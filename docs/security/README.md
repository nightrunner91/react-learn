# Безопасность

Раздел объясняет, как защищать веб-приложения на уровне фронтенда: от классических XSS и CSRF до Server Actions, CSP, секретов, авторизации и безопасности зависимостей.

## Начни здесь

1. **[Безопасность веб-приложений](./security.md)** — комплексный гайд по угрозам и защите.

### Пройди по порядку

- XSS — виды, защита, экранирование
- CSRF — механизм атаки и токены
- Безопасность Server Actions в Next.js
- Content Security Policy
- Управление секретами
- Аутентификация и авторизация
- HTTP-заголовки безопасности
- Безопасность зависимостей
- Чек-лист безопасности

## Как пользоваться

1. Пойми базовые угрозы: XSS и CSRF.
2. Внедри CSP и security-заголовки в проект.
3. Регулярно проверяй зависимости на уязвимости.
4. Используй чек-лист перед релизом.
