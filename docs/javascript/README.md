# JavaScript Core

Раздел углубляет понимание языка: как JS хранит данные, работает область видимости, замыкания, `this`, прототипы, Event Loop и продвинутые возможности. Ориентирован на собеседования и уверенную разработку.

Раздел находится в процессе реструктуризации: монолитная статья `js-core.md` разбивается на тематические файлы, как это сделано в разделах `typescript/`, `react/`, `testing/`.

## Рекомендуемый порядок чтения

1. Типы данных и приведение типов
2. Область видимости и hoisting
3. Замыкания
4. Контекст выполнения и `this`
5. Прототипы и классы
6. Event Loop
7. Асинхронность: Promise, async/await
8. Модули
9. Коллекции, итераторы, генераторы
10. Proxy и Reflect
11. Функциональное программирование
12. Память и производительность
13. Практические задачи

## Статьи

### Готовые

- **[Типы данных и приведение типов](./js-data-types.md)** — примитивы и объекты, `typeof`, coercion, `==`/`===`, `Object.is`, `Number.isNaN`, собеседовательские ловушки.
- **[Область видимости и hoisting](./js-scope-hoisting.md)** — `var`/`let`/`const`, TDZ, лексическое окружение, hoisting функций и классов, практические примеры.
- **[Замыкания](./js-closures.md)** — определение и работа под капотом, приватные переменные, каррирование, IIFE, модули как замыкания, stale closures в React, практические задачи.
- **[Контекст выполнения и `this`](./js-this.md)** — правила определения `this`, `call`/`apply`/`bind`, потеря контекста, стрелочные функции, `this` в классах и обработчиках событий React, практические задачи.

## Как пользоваться

1. Читай по порядку — темы логически связаны.
2. После каждой статьи пройди чеклист вопросов в её конце.
3. Возвращайся к замыканиям, `this` и Event Loop перед собеседованиями.
4. После завершения теории переходи к практическим задачам.

> Легаси-версия всего раздела в одном файле пока доступна как [`js-core.md`](./js-core.md), но в дальнейшем она будет заменена новыми статьями.
