# JavaScript Core

Раздел углубляет понимание языка: как JS хранит данные, работает область видимости, замыкания, `this`, прототипы, Event Loop и продвинутые возможности. Ориентирован на собеседования и уверенную разработку.

## Начни здесь

1. **[JavaScript Core](./js-core.md)** — единый гайд по внутреннему устройству языка.

### Пройди по порядку

- Как JavaScript хранит данные
- Область видимости и hoisting
- Замыкания
- Контекст выполнения и `this`
- Прототипное наследование
- Event Loop и асинхронность
- Типы данных и неявное преобразование
- Proxy, WeakMap, генераторы

## Как пользоваться

1. Читай по порядку — темы логически связаны.
2. После каждого раздела реши несколько задач на практике.
3. Возвращайся к замыканиям, `this` и Event Loop перед собеседованиями.
