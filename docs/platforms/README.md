# Платформы

Раздел расширяет React за пределы классического веба: Progressive Web Apps для веб-приложений, React Native для мобильных устройств и Preact как лёгкий альтернативный рантайм.

## Начни здесь

1. **[Progressive Web Apps (PWA)](./pwa.md)** — манифест, Service Workers, офлайн, push, кэширование, установка на устройство.

## Специализированные темы

- **[React Native](./react_native_intro.md)** — компоненты, стилизация, навигация, состояние, нативные модули, Expo vs Bare, публикация.
- **[Preact](./preact.md)** — лёгкий React-совместимый рантайм, миграция через `preact/compat`, Preact Signals, trade-offs.

## Как пользоваться

1. PWA — первый шаг к нативному опыту в браузере.
2. React Native — когда нужно полноценное мобильное приложение с общей кодовой базой.
3. Preact — когда важен размер бандла или нужен лёгкий React-совместимый рантайм.
4. Оценивай ограничения каждой платформы перед выбором.
