# Взаимодействие с API

Раздел сравнивает подходы к коммуникации клиента с сервером: классический REST, гибкий GraphQL и двунаправленный WebSocket в React/Next.js.

## Начни здесь

1. **[REST](./rest.md)** — архитектурный стиль, ресурсы, HTTP-методы, коды ответов, HATEOAS, best practices.

## Продвинутые темы

- **[GraphQL vs REST](./graphql-vs-rest.md)** — сравнение подходов, схемы, запросы, мутации, подписки, когда что выбрать.

## Специализированные темы

- **[WebSocket в React и Next.js](./websocket_react_next.md)** — real-time, переподключения, интеграция с состоянием, масштабирование.

## Как пользоваться

1. REST — база для большинства проектов.
2. GraphQL — когда нужна гибкость клиентских запросов и много связанных сущностей.
3. WebSocket — для real-time: чаты, уведомления, совместное редактирование.
