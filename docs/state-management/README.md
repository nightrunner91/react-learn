# Управление состоянием

Раздел объединяет три аспекта работы с данными на клиенте: браузерные хранилища, клиентское состояние через Zustand и серверное состояние через TanStack Query.

## Начни здесь

1. **[Локальные хранилища данных](./client-storage.md)** — localStorage, sessionStorage, cookies, IndexedDB, безопасность и ограничения.

## Клиентское состояние

- **[Zustand](./zustand.md)** — лёгкий стор, селекторы, мидлвары, миграция с Redux.

## Серверное состояние

- **[TanStack Query](./tanstack_query.md)** — кэширование, мутации, фоновое обновление, продвинутые сценарии.

## Как пользоваться

1. Пойми, где живут твои данные: в браузере, в памяти приложения или на сервере.
2. Для глобального клиентского состояния используй Zustand.
3. Для API — TanStack Query вместо самописных fetch-обёрток.
4. Хранилища браузера — для персистентности, куки — для аутентификации и трекинга.
