# Архитектура

Раздел про проектирование фронтенда: принципы чистого кода, классические архитектурные паттерны, React/Vue-паттерны компонентов и паттерн Backend for Frontend.

## Начни здесь

1. **[DRY, KISS, YAGNI](./dry-kiss-yagni-frontend.md)** — базовые принципы простого и поддерживаемого кода.
2. **[SOLID](./solid-frontend.md)** — пять принципов и их практическое применение во фронтенде.

## Продвинутые темы

- **[MVC, MVP, MVVM](./mvc-mvvm-article.md)** — классические архитектурные паттерны в контексте React и Vue.
- **[Паттерны GoF](./gof_patterns_frontend.md)** — фабрика, декоратор, синглтон, наблюдатель.
- **[Паттерны проектирования React / Next.js](./design_patterns.md)** — композиция, render props, custom hooks, структура файлов.

## Специализированные темы

- **[Backend for Frontend](./backend_for_frontend.md)** — адаптация API под нужды клиента.

## Как пользоваться

1. Начни с базовых принципов — они влияют на каждую строчку кода.
2. Применяй архитектурные паттерны осознанно, а не ради паттерна.
3. Проектируй структуру под команду и масштаб проекта.
4. BFF — когда API не подходит под UI и нельзя его изменить.
