# Алгоритмы

Раздел вводит алгоритмическую сложность и Big O с практической точки зрения фронтенд-разработчика и подготовки к собеседованиям.

## Начни здесь

1. **[Алгоритмическая сложность и Big O](./big-o-notation.md)** — типы сложностей, пространственная сложность, шпаргалка, типичные задачи, паттерны оптимизации, ресурсы для практики.

## Как пользоваться

1. Разберись с O(1), O(n), O(log n), O(n²) и их визуальными примерами.
2. Практикуйся на типичных задачах с собеседований.
3. Используй Big O при анализе собственных решений.
