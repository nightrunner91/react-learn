# Сравнения

Раздел помогает быстро сориентироваться в различиях между Vue и React: реактивность, жизненный цикл, props, события, директивы и Composition API vs Hooks.

## Начни здесь

1. **[Шпаргалка Vue ↔ React](./vue-react-cheatsheet.md)** — сопоставление ключевых концепций двух фреймворков.

### Что внутри

- Реактивность и состояние
- Жизненный цикл
- Props и события
- Provide / Inject vs Context
- Template Refs
- Директивы vs JSX
- Composition API vs Hooks
- Ключевые отличия

## Как пользоваться

1. Используй как справочник при переходе между фреймворками.
2. Сравнивай концепции, а не синтаксис — это ускоряет адаптацию.
3. Возвращайся при ревью кода на незнакомом стеке.
